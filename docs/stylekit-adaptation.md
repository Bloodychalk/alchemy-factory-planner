# StyleKit 外观适配与验收

依据：[俏皮野兽派中文 design.md](https://www.stylekit.top/api/design/neo-brutalist-playful/design.md?locale=zh) 的 Implementation Contract。未连接 StyleKit MCP，已读取完整中文文档。

## 实施范围

沿用现有单页、HTML 控件、1050px/680px 断点和原计算器画布。修改仅涉及样式、静态 SVG 图标、字体资源和主题缓存版本。流程图适配集中于 `runtime.js` 的 CSS 字符串；计算、数据、Worker、存档和交互处理函数保持不变。不增加介绍文案或功能。

## 项目适配

- 白底、4px 黑框、直角和无模糊硬阴影；使用珊瑚红、薄荷绿、阳光黄三种强调色。
- Inter 700/900 自托管，附 SIL OFL；中文使用系统中文字体回退。标题和指标使用 28/40px，数据标签 14px。
- 页面上限 1200px。计算器保留侧栏和结果区，指标改为两列，确保长数值可读。控件与分区采用 8px 基础间距；工具页面不套用营销页面的 80px 大段留白。
- 最多四个元素默认倾斜，角度 -2 到 3 度；流程节点保持正向，避免影响连线对齐。300ms 回弹交互，按压移位并收起阴影。
- 主按钮保留珊瑚底，使用黑字，保证文字对比度；不照搬示例中的珊瑚底白字。保留清楚的虚线禁用状态、错误提示和 4px 键盘焦点。
- 品牌、行动按钮和图形工具按钮使用 SVG，不新增 emoji 装饰。
- `prefers-reduced-motion: reduce` 关闭过渡、倾斜交互和图形连线动画。

## 实际验收

- 已运行网页构建、静态资源/发布边界检查、修改模块的语法检查和 diff 空白检查。
- 已检查桌面、375px、320px 初始布局与高级设置；两种窄屏页面宽度均未超过视口。375px 计算结果和流程图也无页面横向溢出。
- 已通过键盘 Tab 检查到目标列表的 4px 焦点；浏览器确认 Inter 已加载。
- 无效 JSON 导入仍显示错误并保留原资料；成功计算后错误提示正常收起。
- 木材基准实际界面结果：60/分钟、2 台锯木机、0.3 原木/分钟。流程图同值，缩放按钮响应正常。
- 浏览器未记录控制台错误。恢复了临时视口设置。

未验证：未切换操作系统的减少动态效果设置进行实机测试（已审查对应 CSS）；未进行跨浏览器或游戏内实际搭建验证。本次没有修改计算逻辑，没有新增或重复运行完整算法测试；发布流程按现有规则自行检查。
