# 使用说明

## 第一次使用

在线版首次打开需要联网取得参考计算器资料；桌面版会下载并校验参考文件，并尝试从 Wiki 校准配方。准备完成后左上角显示“资料已就绪”。使用前可先打开图形模式，让需要的图形资源也进入缓存；桌面缓存一次下载完整参考资源。

1. 在左侧搜索中输入中文或英文物品名，从列表中选择产物。
2. 填写目标产量，单位可选个/分钟、个/秒、秒/个。秒/个表示两个产物之间的目标间隔，例如 2 秒/个等于 30 个/分钟。
3. 点击“计算推荐产线”。计算在后台进行，可取消；失败时保留之前的结果。
4. 在简介模式查看采购与机器清单，在图形模式查看原料、加工、回流及净交付。拖动节点和缩放仅改变图的位置，不改变配平数值。
5. 使用“保存方案”下载 JSON；“打开方案”恢复参数并重新复核。使用“导出文字”保存完整文本报告。

## 生产设置

研究等级默认 0。自动推荐会尝试不同配方、燃料、肥料和炼金组合，并优先减少持续采购支出。高级设置可以固定目标配方、燃料、肥料、加热设备与萃取高度。选择高级炼金炉配方后可以指定催化剂；选择自定义悖论配方后可以指定投入物品。

工具默认包括燃料与肥料自产链。若目标产物本身也被燃烧或施肥，目标量表示扣除内部使用后的净交付量。副产物先用于满足生产需求，剩余部分单独列出。种子、世界树种子及设备材料是一次性建造或启动需求，单独列出，不伪装成持续采购。

显示的机器建造数向上取整，同时提供理论台数和利用率。热耗按实际加工负载计算；完整报告另列整数设备满负载热耗。加热设备数量依据参考引擎的供热槽位模型估算，不代表游戏格子坐标布局。

## JSON 资料

“导出资料”得到标准 JSON，包含 `items`、`machines`、`recipes` 和来源信息。可修改价格、配方或添加物品后再导入。引用物品必须存在，数量与时间必须有效；文件不执行脚本。导入失败保留原资料和翻译。旧版中文键名会映射回规范英文名称。

桌面上的“校准 Wiki”会更新可对应的配方、价格、燃料值与营养参数，并保留参考项目独有的设备变体和特殊规则。Wiki 数字 ID 只用于来源/规则映射，不直接覆盖图标 ID。动态机制和更新情况写入 JSON 的 `metadata`。

## 离线、缓存和隐私

浏览器资料存在该浏览器的本地缓存中，清理浏览器数据会丢失缓存。保存到 JSON 的方案可以跨浏览器导入。网页首次准备和首次图形资源加载需要网络；完成缓存后支持离线重新打开。

桌面存档和参考资料位于：

- macOS：`~/Library/Application Support/AlchemyFactoryPlanner/`
- Windows：`%LOCALAPPDATA%/AlchemyFactoryPlanner/`

桌面不把个人存档上传服务器。外部链接交系统浏览器打开。网页和桌面保存文件使用不同的平台适配方式。

## 安装与兼容

解压对应平台的程序包，运行 `AlchemyFactoryPlanner.exe` 或 `AlchemyFactoryPlanner.app`，无需安装 Python。Windows 若提示缺少 WebView2，请从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)安装 Evergreen Runtime 后重试。Mac 包没有开发者公证；系统若要求确认来源，使用系统提供的打开流程。

## 结果边界

这是限时推荐，不是全局最优证明。概率产量是长期平均值，需要缓冲库存；开机启动和短时随机波动不由稳态配平保证。无法供应、缺少价格、自供发散或守恒检查失败的路线不会显示为完整推荐。遇到复杂路线未找到方案时，可以固定配方/燃料或先导入已核验的资料再计算。
