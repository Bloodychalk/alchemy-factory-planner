# 使用说明

打开[网页版](https://bloodychalk.github.io/alchemy-factory-planner/)，选择产物和产量后计算。单位支持个/分钟、个/秒和秒/个。高级设置可指定配方、燃料、肥料、研究等级、催化剂和悖论投入。

目标量表示扣除内部消耗后的净交付量。简介模式列出采购和建造数量；图形模式-总览合并同类生产步骤，图形模式-详细逐台显示设备、分流合流、燃料和肥料连接。两种图均可拖动和缩放，详细图点击节点查看端口；优先支路带有“优先”标记。同工序设备最多 4 台时竖排，更多时排成矩阵；分流三角朝右、合流三角朝左，物料均左入右出。两种图共用动态虚线/静态箭纹设置。方案保存为 JSON，打开后重新计算并恢复匹配的布局；旧版本方案仍可打开，资料 JSON 可导入导出。

详细图是平均吞吐接线图，未计算格子摆放。物流规则不足的路线会列出缺失项，仍可查看总览；支持范围见[详细规划说明](detailed-planning.md)。

首次准备参考资料需要网络，缓存之后可离线使用。清理浏览器数据会清除缓存和本地记录，重要方案请另存 JSON。Wiki 转换工具位于开发目录 `data_tools/wiki.py`；浏览器不直接请求受 CORS 限制的 Wiki 页面。

推荐为限时有界搜索，不保证全局最优。概率产量按长期平均计算，实际搭建需要缓冲库存。
